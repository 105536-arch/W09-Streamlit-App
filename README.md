
# W09 Streamlit 我的學習名片

## 一、作品介紹
這是一個使用 Python 和 Streamlit 製作的 Web App，
可以讓使用者輸入姓名與感興趣的資訊主題，
建立自己的學習名片。

## 二、使用技術
- Python 3.14
- Streamlit 1.67.0
- VS Code

## 三、作品功能
1. 輸入姓名
2. 輸入感興趣的資訊主題
3. 點擊按鈕建立學習名片
4. 檢查欄位是否為空值
5. 顯示學習名片與成功訊息
6. 顯示個人學習目標
